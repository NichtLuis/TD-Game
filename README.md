# TD-Game für unser TeKo Projekt
Hier ist unser Tower Defence Game für das TeKo Projekt der E2 im Schuljahr 2024/2025
Das Spiel lässt sich nur durch den Live Server in VS Code starten, da sonst die Dateipfade nicht übereinstimmen
Falls das Spiel zu schwer sein sollte, lassen sie einfach ein 4K Youtube Video im Hintergrund laufen lassen, da die Gegner auf der Browserleistung basieren
